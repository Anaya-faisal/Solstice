# Solstice

Solstice minimizes administrative overhead by autonomously managing user birthdays, anniversary alerts, and custom celebration for user to make them feel noticed Because every single soul in our little corner of the internet deserves to feel seen, celebrated, and remembered—right down to the exact stroke of midnight in their own quiet corner of the world

## Features

## Features

| Feature | Description |
|---|---|
| Rendered calendar dashboard | Generates a calendar image highlighting birthdays for the selected month. |
| Month/Year navigation | Uses dropdowns and buttons to browse any month. |
| Set/edit birthday | Modal form to save birth month, day, and timezone offset. |
| Remove birthday | Button with confirmation to clear records. |
| Auto-purge on leave | Automatically deletes records if a user leaves the server. |
| Per-user timezone midnight ping | Celebrates users at their local midnight based on stored offsets. |
| Temporary birthday role | Assigns a 24-hour birthday role, which is automatically removed. |
| Admin override | Moderator slash commands to set or clear user birthdays. |
| Locked celebration channel | Restricts chat in `#birthday-corner` while allowing modal and button interactions. |
